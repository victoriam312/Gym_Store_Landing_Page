# Gym Store Landing Page

## Descripción del Proyecto

Este proyecto es una landing page y un sitio web estático desarrollado como proyecto final de la asignatura **Lenguaje de Marcas y Sistemas de Gestión de la Información (LM)** del ciclo formativo DAM.

Simula el portal web de una tienda de productos fitness, con el objetivo principal de demostrar el dominio de la estructura HTML semántica y el diseño CSS profesional.

## Características Destacadas y Habilidades Demostradas

* **HTML Semántico:** Uso de etiquetas (`<header>`, `<nav>`, `<section>`, `<footer>`) para una estructura clara y accesible.
* **Maquetación con CSS3:** Implementación de técnicas de diseño como:
    * Uso de `display: flex` para la correcta distribución de la galería de productos y el equipo.
    * Diseño **Fijo (Fixed)** para la barra de navegación superior.
    * Estilos **Hover** y transiciones para una mejor experiencia de usuario.
* **Formularios Avanzados:** Creación de dos formularios completos:
    * Un formulario de contacto simple.
    * Un formulario de aplicación de empleo estructurado con diferentes tipos de entrada (`tel`, `date`, `file`) y agrupaciones (`<fieldset>`, `<legend>`).
* **Manejo Multimedia:** Galerías de imágenes de productos y del equipo, optimizadas para web.

## Tecnologías Utilizadas

| Tecnología | Propósito |
| :--- | :--- |
| **HTML5** | Estructura y contenido semántico de la página. |
| **CSS3** | Estilización, *responsive design* y maquetación (Flexbox). |
